API documentation

Base URL

http://localhost:3000/api

Endpoints

  • GET /api/health
  • GET /api/users
  • GET /api/tickets
  • GET /api/tickets?status=Open&priority=High&q=login
  • GET /api/tickets/:id
  • POST /api/tickets
  • PATCH /api/tickets/:id
  • DELETE /api/tickets/:id

Example POST body

{
  "title": "New defect from API",
  "description": "Created with Playwright request context",
  "priority": "High",
  "project": "Automation Practice",
  "assigneeId": 1
}
